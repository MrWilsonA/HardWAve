# 3D Model Assets Directory

Letakkan file 3D model hasil download dari Sketchfab (.glb atau .gltf) di folder ini:

- `gpu.glb` - Model RTX 3090 / Kartu Grafis
- `fan.glb` - Model RGB Cooling Fan
- `ssd.glb` - Model Samsung M.2 SSD
- `motherboard.glb` - Model NZXT N7 Z490 Motherboard
- `ram.glb` - Model HyperX Fury RAM

Komponen 3D Canvas di HardWAve otomatis akan mendeteksi dan me-load model yang ada di folder ini.
